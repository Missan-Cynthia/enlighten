# English letter name and phonics audio

Each WAV plays the letter name three times, followed by its common beginning phonics sound three times.

The files were synthesized with the installed Microsoft Zira en-US voice using explicit Microsoft UPS phoneme markup, so playback does not depend on the visitor's device voice.

Primary sound mapping:

`A /æ/, B /b/, C /k/, D /d/, E /ɛ/, F /f/, G /ɡ/, H /h/, I /ɪ/, J /dʒ/, K /k/, L /l/, M /m/, N /n/, O /ɑ/, P /p/, Q /kw/, R /ɹ/, S /s/, T /t/, U /ʌ/, V /v/, W /w/, X /ks/, Y /j/, Z /z/`

These are the common introductory phonics values. Letters such as C, G, X, and vowel letters can represent additional sounds in other words.
